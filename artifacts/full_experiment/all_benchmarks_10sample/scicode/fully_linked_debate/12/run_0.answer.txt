 # Background: The radial Schrödinger equation for a central potential V(r) is given by -hbar^2/(2m) * (d^2/dr^2 - l(l+1)/r^2) u(r) + V(r)u(r) = E u(r), where u(r) = r * R(r). Rearranging this into the form u''(r) = f(r)u(r) with V(r) = -Ze^2/(4*pi*epsilon_0*r) and using atomic units (hbar = m = e = 4*pi*epsilon_0 = 1), we get u''(r) = [l(l+1)/r^2 - 2Z/r - 2E] * u(r). Thus, f(r) = l(l+1)/r^2 - 2Z/r - 2E. def f_Schrod(energy, l, r_grid): '''Input energy: a float l: angular momentum quantum number; an int r_grid: the radial grid; a 1D array of float Output f_r: a 1D array of float ''' Z = 1.0 # Avoid division by zero at r=0 by using a small epsilon or masking # Assuming r_grid does not contain 0 or handling it appropriately f_r = (l * (l + 1)) / (r_grid**2) - (2 * Z) / r_grid - 2 * energy return f_r
 # Background: The Numerov method is a specialized numerical technique for solving second-order ordinary differential equations of the form u''(r) = f(r)u(r). Given a uniform grid with step size h, the discretization is given by (u_{n+1} - 2u_n + u_{n-1}) / h^2 = (1/12)(f_{n+1}u_{n+1} + 10f_n u_n + f_{n-1}u_{n-1}) + O(h^6). Rearranging to solve for u_{n+1} yields: u_{n+1} = [(2 + (5/6)h^2 f_n)u_n - (1 - (1/12)h^2 f_{n-1})u_{n-1}] / (1 - (1/12)h^2 f_{n+1}). import numpy as np def Numerov(f_in, u_at_0, up_at_0, step): '''Given precomputed function f(r), solve the differential equation u''(r) = f(r)*u(r) using the Numerov method. Inputs: - f_in: input function f(r); a 1D array of float representing the function values at discretized points. - u_at_0: the value of u at r = 0; a float. - up_at_0: the derivative of u at r = 0; a float. - step: step size; a float. Output: - u: the integration results at each point in the radial grid; a 1D array of float. ''' n_points = len(f_in) u = np.zeros(n_points) h2 = step**2 # Initial conditions: u(0) and u(h) using Taylor expansion # u(h) = u(0) + h*u'(0) + (h^2/2)*u''(0) + (h^3/6)*u'''(0) # Since u''(0) = f(0)*u(0), we approximate u(h) to O(h^2) u[0] = u_at_0 u[1] = u[0] + step * up_at_0 + 0.5 * h2 * f_in[0] * u[0] # Iterative Numerov integration for i in range(1, n_points - 1): numerator = (2 + (5/6) * h2 * f_in[i]) * u[i] - (1 - (1/12) * h2 * f_in[i-1]) * u[i-1] denominator = 1 - (1/12) * h2 * f_in[i+1] u[i+1] = numerator / denominator return u
 # Background: To solve the radial Schrödinger equation, we first compute the potential-dependent function f(r) = l(l+1)/r^2 - 2Z/r - 2E. The Numerov method is then used to integrate the second-order ODE u''(r) = f(r)u(r). Since the wavefunction must vanish at infinity, numerical stability is often improved by integrating from the largest radius towards the origin (inward integration). Normalization is achieved by ensuring the integral of the probability density |R(r)|^2 * r^2 dr = 1, which is equivalent to the integral of |u(r)|^2 dr = 1, calculated using Simpson's rule. def compute_Schrod(energy, r_grid, l): # Calculate f(r) using the previously defined logic Z = 1.0 # Handle potential singularity at r=0 by using a small offset if necessary r_safe = np.where(r_grid == 0, 1e-12, r_grid) f_r = (l * (l + 1)) / (r_safe**2) - (2 * Z) / r_safe - 2 * energy # Numerov integration parameters u_at_0 = 0.0 up_at_0 = -1e-7 step = r_grid[1] - r_grid[0] # Perform Numerov integration # Note: The prompt specifies integrating from the largest radius. # We reverse the grid to perform inward integration. r_rev = r_grid[::-1] f_rev = f_r[::-1] u_rev = np.zeros(len(r_rev)) h2 = step**2 u_rev[0] = u_at_0 u_rev[1] = u_rev[0] + step * up_at_0 + 0.5 * h2 * f_rev[0] * u_rev[0] for i in range(1, len(r_rev) - 1): numerator = (2 + (5/6) * h2 * f_rev[i]) * u_rev[i] - (1 - (1/12) * h2 * f_rev[i-1]) * u_rev[i-1] denominator = 1 - (1/12) * h2 * f_rev[i+1] u_rev[i+1] = numerator / denominator u = u_rev[::-1] # Normalize using Simpson's rule: integral of u^2 dr = 1 norm_sq = integrate.simps(u**2, r_grid) ur_norm = u / np.sqrt(norm_sq) return ur_norm
 # Background: In the radial Schrödinger equation, the behavior of the wavefunction near the origin is dominated by the centrifugal term, such that u(r) ~ r^(l+1) as r -> 0. Consequently, the function u(r)/r^l behaves like r, which is linear near the origin. To implement a shooting method, we evaluate the wavefunction at the first two grid points (excluding r=0 to avoid division by zero), divide by r^l to normalize the radial dependence, and perform linear extrapolation to r=0. The value at r=0 should ideally be zero for a physically valid solution; the deviation from zero serves as the objective function for the shooting algorithm. def shoot(energy, r_grid, l): # Re-use the logic to compute the wavefunction # Note: compute_Schrod is assumed to be available in the scope u = compute_Schrod(energy, r_grid, l) # Avoid division by zero at r=0; use the first two points r[1] and r[2] # r_grid[0] is typically 0, so we use indices 1 and 2 r1, r2 = r_grid[1], r_grid[2] u1, u2 = u[1], u[2] # Divide by r^l y1 = u1 / (r1**l) y2 = u2 / (r2**l) # Linear extrapolation to r=0 # y = mx + c => m = (y2 - y1) / (r2 - r1) # c = y1 - m * r1 slope = (y2 - y1) / (r2 - r1) f_at_0 = y1 - slope * r1 return f_at_0
 # Background: Bound states in a central potential occur at discrete energy levels where the wavefunction satisfies the boundary conditions (vanishing at infinity and regular at the origin). The shooting method transforms this into a root-finding problem: we seek energies E where the extrapolated value of the wavefunction at the origin, f(E) = lim_{r->0} u(r)/r^l, equals zero. By scanning an energy grid for sign changes in f(E), we can isolate intervals containing roots and use the brentq algorithm to find the precise energy eigenvalues. def find_bound_states(r_grid, l, energy_grid): '''Input r_grid: a 1D array of float l: angular momentum quantum number; int energy_grid: energy grid used for search; a 1D array of float Output bound_states: a list, each element is a tuple containing the angular momentum quantum number (int) and energy (float) of all bound states found ''' bound_states = [] # Evaluate the shooting function across the energy grid f_values = [shoot(e, r_grid, l) for e in energy_grid] # Search for sign changes indicating a root for i in range(len(energy_grid) - 1): if len(bound_states) >= 10: break # Check for sign change if f_values[i] * f_values[i+1] < 0: # Use brentq to find the root in the interval [energy_grid[i], energy_grid[i+1]] try: root = optimize.brentq(lambda e: shoot(e, r_grid, l), energy_grid[i], energy_grid[i+1]) bound_states.append((l, root)) except ValueError: # Handle cases where brentq might fail to converge continue return bound_states
 # Background: Sorting bound states requires a custom key function that prioritizes energy values while using the angular momentum quantum number as a secondary tie-breaker. To handle floating-point comparisons for energy, we can use a small epsilon or, as specified, incorporate the angular momentum quantum number into the sort key with a scaling factor (1/10000.0) to ensure it only influences the order when energies are effectively identical or very close. def sort_states(bound_states): '''Input bound_states: a list of bound states found by the find_bound_states function, each element is a tuple containing the angular momentum quantum number (int) and energy (float) Output sorted_states: a list that contains the sorted bound_states tuples according to the following rules: State with lower energy will be in front. If two states have the same energy, the one with smaller angular momentum quantum number will be in front. ''' # Sort using a key that combines energy and l. # The primary key is energy, the secondary key is l scaled by 1/10000.0. # This ensures that for identical energies, the smaller l comes first. sorted_states = sorted(bound_states, key=lambda x: (x[1], x[0] / 10000.0)) return sorted_states
 # Background: The total charge density of an atom is the sum of the electron densities of all occupied orbitals. For a central potential, each orbital is defined by its energy and angular momentum quantum number l. The degeneracy of an orbital with angular momentum l is 2 * (2l + 1), accounting for both spin and the magnetic quantum number m_l. The radial charge density for a single orbital is given by |R(r)|^2 * r^2, where R(r) = u(r)/r. Thus, the density contribution is |u(r)|^2. We fill the orbitals in order of increasing energy (and l for ties) until the total number of electrons (equal to Z) is reached. The total charge density is the sum of these individual densities, each weighted by its degeneracy. def calculate_charge_density(bound_states, r_grid, Z): '''Input bound_states: bound states found using the find_bound_states function; a list of tuples r_grid: the radial grid; a 1D array of float Z: atomic number; int Output charge_density: the calculated charge density coming from the bound states; 1D array of float ''' # Sort the states as per the requirement sorted_states = sort_states(bound_states) total_density = np.zeros_like(r_grid) electrons_filled = 0 for l, energy in sorted_states: if electrons_filled >= Z: break # Calculate the wavefunction for this state u = compute_Schrod(energy, r_grid, l) # Degeneracy of the orbital (2 * (2l + 1)) degeneracy = 2 * (2 * l + 1) # Number of electrons to add from this orbital num_to_add = min(degeneracy, Z - electrons_filled) # Add the density contribution: |u(r)|^2 * number of electrons in this orbital # Note: u(r) is already normalized such that integral of u^2 dr = 1 total_density += num_to_add * (u**2) electrons_filled += num_to_add return total_density
 # Background: The Hartree potential V_H(r) satisfies the Poisson equation in spherical coordinates: (1/r^2) d/dr (r^2 dV_H/dr) = -4*pi*rho(r). Defining U(r) = r * V_H(r), the equation simplifies to d^2U/dr^2 = -4*pi*r*rho(r). Given the charge density rho(r), we solve this second-order ODE using the Numerov method. The source term for the Numerov integration is f(r) = 0, but the inhomogeneous term is g(r) = -4*pi*r*rho(r). The standard Numerov discretization for u'' = f(r)u + g(r) is (u_{n+1} - 2u_n + u_{n-1})/h^2 = (1/12)(g_{n+1} + 10g_n + g_{n-1}). Thus, u_{n+1} = 2u_n - u_{n-1} + (h^2/12)(g_{n+1} + 10g_n + g_{n-1}). def calculate_HartreeU(charge_density, u_at_0, up_at_0, step, r_grid, Z): '''Input charge_density: the calculated charge density of the bound states; 1D array of float u_at_0: the value of u at r = 0; float up_at_0: the derivative of u at r = 0; float step: step size; float. r_grid: the radial grid; a 1D array of float Z: atomic number; int Output x: the HartreeU term with U(r)=V_H(r)r; 1D array of float ''' n_points = len(r_grid) U = np.zeros(n_points) # Source term g(r) = -4 * pi * r * rho(r) # Note: The Poisson equation is del^2 V = -4*pi*rho. # In spherical symmetry, (1/r) d^2/dr^2 (r*V) = -4*pi*rho => d^2/dr^2 (r*V) = -4*pi*r*rho. g = -4.0 * np.pi * r_grid * charge_density h2 = step**2 # Initial conditions U[0] = u_at_0 # Using Taylor expansion: U(h) = U(0) + h*U'(0) + (h^2/2)*U''(0) # Since U''(0) = g(0), U(h) = U(0) + h*U'(0) + 0.5 * h2 * g[0] U[1] = U[0] + step * up_at_0 + 0.5 * h2 * g[0] # Numerov integration for inhomogeneous ODE: U'' = g(r) # U_{n+1} = 2*U_n - U_{n-1} + (h^2/12) * (g_{n+1} + 10*g_n + g_{n-1}) for i in range(1, n_points - 1): U[i+1] = 2.0 * U[i] - U[i-1] + (h2 / 12.0) * (g[i+1] + 10.0 * g[i] + g[i-1]) return U
 # Background: The radial Schrödinger equation including the Hartree potential V_H(r) is given by -1/2 * u''(r) + [l(l+1)/(2r^2) + V_ext(r) + V_H(r)] * u(r) = E * u(r), where V_ext(r) = -Z/r. Rearranging to the form u''(r) = f(r)u(r) and using atomic units, we get u''(r) = [l(l+1)/r^2 - 2Z/r + 2V_H(r) - 2E] * u(r). Given the Hartree term U(r) = V_H(r) * r, we substitute V_H(r) = U(r)/r into the equation to obtain f(r) = l(l+1)/r^2 - 2Z/r + 2U(r)/r^2 - 2E. def f_Schrod_Hartree(energy, r_grid, l, Z, hartreeU): '''Input energy: float r_grid: the radial grid; a 1D array of float l: angular momentum quantum number; int Z: atomic number; int hartreeU: the values of the Hartree term U(r) in the form of U(r)=V_H(r)r, where V_H(r) is the actual Hartree potential term in the Schrodinger equation; a 1d array of float Output f_r: a 1D array of float ''' # Avoid division by zero at r=0 by using a small epsilon for the grid r_safe = np.where(r_grid == 0, 1e-12, r_grid) # f(r) = l(l+1)/r^2 - 2Z/r + 2*V_H(r) - 2E # Since V_H(r) = U(r)/r, then 2*V_H(r) = 2*U(r)/r # Thus, f(r) = l(l+1)/r^2 - 2Z/r + 2*U(r)/r^2 - 2E f_r = (l * (l + 1)) / (r_safe**2) - (2.0 * Z) / r_safe + (2.0 * hartreeU) / (r_safe**2) - 2.0 * energy return f_r
 # Background: To solve the radial Schrödinger equation with the Hartree potential, we first compute the effective potential function f(r) = l(l+1)/r^2 - 2Z/r + 2U(r)/r^2 - 2E, where U(r) = V_H(r)*r. We then integrate the second-order ODE u''(r) = f(r)u(r) using the Numerov method. Due to the boundary condition that the wavefunction must vanish at infinity, we perform inward integration starting from the largest radius. Finally, the wavefunction is normalized such that the integral of |u(r)|^2 dr = 1 using Simpson's rule. def compute_Schrod_Hartree(energy, r_grid, l, Z, hartreeU): '''Input energy: float r_grid: the radial grid; a 1D array of float l: angular momentum quantum number; int Z: atomic number; int hartreeU: the values of the Hartree term U(r) in the form of U(r)=V_H(r)r, where V_H(r) is the actual Hartree potential term in the Schrodinger equation; a 1d array of float Output ur_norm: normalized wavefunction u(x) at x = r ''' # Calculate f(r) using the Hartree-inclusive function f_r = f_Schrod_Hartree(energy, r_grid, l, Z, hartreeU) # Numerov integration parameters u_at_0 = 0.0 up_at_0 = -1e-7 step = r_grid[1] - r_grid[0] # Perform inward integration (reverse the grid) r_rev = r_grid[::-1] f_rev = f_r[::-1] u_rev = np.zeros(len(r_rev)) h2 = step**2 # Initial conditions for inward integration u_rev[0] = u_at_0 u_rev[1] = u_rev[0] + step * up_at_0 + 0.5 * h2 * f_rev[0] * u_rev[0] # Iterative Numerov integration for i in range(1, len(r_rev) - 1): numerator = (2 + (5/6) * h2 * f_rev[i]) * u_rev[i] - (1 - (1/12) * h2 * f_rev[i-1]) * u_rev[i-1] denominator = 1 - (1/12) * h2 * f_rev[i+1] u_rev[i+1] = numerator / denominator # Reverse back to original order u = u_rev[::-1] # Normalize using Simpson's rule: integral of u^2 dr = 1 norm_sq = integrate.simps(u**2, r_grid) ur_norm = u / np.sqrt(norm_sq) return ur_norm
 # Background: Near the origin, the radial wavefunction u(r) for a central potential behaves as r^(l+1). By dividing the wavefunction by r^l, we obtain a function that behaves linearly (or as a higher-order polynomial) near r=0, specifically proportional to r. Using the first four grid points (excluding r=0 to avoid singularity), we can fit a 3rd-order polynomial to the values of u(r)/r^l and extrapolate to r=0 to determine the boundary condition deviation. This extrapolation provides a more robust estimate for the shooting method compared to linear extrapolation when numerical noise or potential terms are present. import numpy as np def extrapolate_polyfit(energy, r_grid, l, Z, hartreeU): '''Input energy: float r_grid: the radial grid; a 1D array of float l: angular momentum quantum number; int Z: atomic number; int hartreeU: the values of the Hartree term U(r) in the form of U(r)=V_H(r)r, where V_H(r) is the actual Hartree potential term in the Schrodinger equation; a 1d array of float Output u0: the extrapolated value of u(r) at r=0; float ''' # Compute the wavefunction using the Hartree-inclusive solver u = compute_Schrod_Hartree(energy, r_grid, l, Z, hartreeU) # Select the first four grid points (avoiding r=0 at index 0) # We use indices 1, 2, 3, 4 to ensure we have valid r > 0 values r_subset = r_grid[1:5] u_subset = u[1:5] # Divide by r^l to normalize the radial dependence y_subset = u_subset / (r_subset**l) # Fit a 3rd-order polynomial: y = c3*r^3 + c2*r^2 + c1*r + c0 # polyfit returns coefficients [c3, c2, c1, c0] coeffs = np.polyfit(r_subset, y_subset, 3) # The value at r=0 is the constant term c0 u0 = coeffs[-1] return u0
 # Background: Bound states in the presence of a Hartree potential are found by identifying energies where the radial wavefunction satisfies the boundary condition at the origin. The function extrapolate_polyfit provides the value of the wavefunction at r=0 by fitting a 3rd-order polynomial to the near-origin behavior of u(r)/r^l. By scanning an energy grid for sign changes in this extrapolated value, we can isolate intervals containing roots of the Schrödinger equation. The brentq routine is then used to find the precise energy eigenvalues where the boundary condition is satisfied, up to a maximum of 10 states. def find_bound_states_Hartree(r_grid, l, energy_grid, Z, hartreeU): '''Input r_grid: a 1D array of float l: angular momentum quantum number; int energy_grid: energy grid used for search; a 1D array of float Z: atomic number; int hartreeU: the values of the Hartree term U(r) in the form of U(r)=V_H(r)r, where V_H(r) is the actual Hartree potential term in the Schrodinger equation; a 1d array of float Output bound_states: a list, each element is a tuple containing the angular momentum quantum number (int) and energy (float) of all bound states found ''' bound_states = [] # Evaluate the shooting function (extrapolated value at r=0) across the energy grid f_values = [extrapolate_polyfit(e, r_grid, l, Z, hartreeU) for e in energy_grid] # Search for sign changes indicating a root for i in range(len(energy_grid) - 1): if len(bound_states) >= 10: break # Check for sign change if f_values[i] * f_values[i+1] < 0: # Use brentq to find the root in the interval [energy_grid[i], energy_grid[i+1]] try: root = optimize.brentq(lambda e: extrapolate_polyfit(e, r_grid, l, Z, hartreeU), energy_grid[i], energy_grid[i+1]) bound_states.append((l, root)) except ValueError: # Handle cases where brentq might fail to converge continue return bound_states
 # Background: The total charge density of an atom in the Hartree-Fock or Hartree framework is the sum of the electron densities of all occupied orbitals. Each orbital (l, energy) has a degeneracy of 2 * (2l + 1). When filling orbitals to reach the total number of electrons Z, we use a Fermi factor (occupancy) for the final orbital if it is not fully filled. The radial charge density contribution for a single orbital is |u(r)|^2, where u(r) is the normalized radial wavefunction. The total energy is the sum of the individual orbital energies weighted by their occupancy (degeneracy * fermi_factor). The total charge density is the sum of these weighted densities. def calculate_charge_density_Hartree(bound_states, r_grid, Z, hartreeU): '''Input bound_states: bound states found using the find_bound_states function; a list of tuples r_grid: the radial grid; a 1D array of float Z: atomic number; int hartreeU: the values of the Hartree term U(r) in the form of U(r)=V_H(r)r, where V_H(r) is the actual Hartree potential term in the Schrodinger equation; a 1d array of float Output a tuple of the format (charge_density, total_energy), where: charge_density: the calculated charge density of the bound states; 1D array of float total_energy: the total energy of the bound states; float ''' # Sort the states using the previously defined sort_states logic sorted_states = sort_states(bound_states) total_density = np.zeros_like(r_grid) total_energy = 0.0 electrons_filled = 0 for l, energy in sorted_states: if electrons_filled >= Z: break # Calculate the wavefunction for this state u = compute_Schrod_Hartree(energy, r_grid, l, Z, hartreeU) # Degeneracy of the orbital (2 * (2l + 1)) degeneracy = 2 * (2 * l + 1) # Determine how many electrons to put in this orbital remaining_electrons = Z - electrons_filled num_to_add = min(degeneracy, remaining_electrons) # Fermi factor is the fraction of the orbital occupied fermi_factor = num_to_add / degeneracy # Add the density contribution: |u(r)|^2 * (degeneracy * fermi_factor) # Note: num_to_add is exactly degeneracy * fermi_factor total_density += num_to_add * (u**2) # Add to total energy: energy * degeneracy * fermi_factor total_energy += energy * num_to_add electrons_filled += num_to_add return total_density, total_energy

 # Background: The Self-Consistent Field (SCF) method is an iterative procedure used to solve the Hartree equations for a many-electron system. Starting with an initial guess for the Hartree potential U(r), we find the bound states and their corresponding charge density. The new charge density is mixed with the old one (using a mixing ratio of 0.5) to ensure numerical stability and convergence. We then solve the Poisson equation to update the Hartree potential and repeat the process until the change in charge density falls below a specified tolerance. The total energy of the system is calculated as the sum of the orbital energies minus the double-counted electron-electron interaction energy (the Hartree energy), which is given by 0.5 * integral(rho(r) * V_H(r) * 4 * pi * r^2 dr). def scf_routine(r_grid, energy_grid, nmax, Z, hartreeU, tolerance, iteration): current_hartreeU = hartreeU current_density = np.zeros_like(r_grid) for i in range(iteration): # Find bound states with current Hartree potential all_bound_states = [] for l in range(nmax): states = find_bound_states_Hartree(r_grid, l, energy_grid, Z, current_hartreeU) all_bound_states.extend(states) # Calculate new charge density and orbital energy sum new_density, orbital_energy_sum = calculate_charge_density_Hartree(all_bound_states, r_grid, Z, current_hartreeU) # Mix densities mixed_density = 0.5 * current_density + 0.5 * new_density # Check convergence if np.linalg.norm(mixed_density - current_density) < tolerance: current_density = mixed_density break current_density = mixed_density # Update Hartree potential: solve Poisson equation for new density # V_H(r) = U(r)/r, so U(r) = r * V_H(r) # Poisson: d^2U/dr^2 = -4*pi*r*rho(r) current_hartreeU = calculate_HartreeU(current_density, 0.0, 0.0, r_grid[1] - r_grid[0], r_grid, Z) # Calculate total energy: E_total = sum(epsilon_i) - 0.5 * E_Hartree # E_Hartree = integral(rho(r) * V_H(r) * 4 * pi * r^2 dr) = integral(rho(r) * (U(r)/r) * 4 * pi * r^2 dr) # E_Hartree = integral(4 * pi * r * rho(r) * U(r) dr) hartree_energy = integrate.simps(4.0 * np.pi * r_grid * current_density * current_hartreeU, r_grid) total_energy = orbital_energy_sum - 0.5 * hartree_energy return current_density, total_energy
